# Egypt Fashion Store (متجر الأزياء المصري)

مستودع الكود المخصص لمشروع متجر أزياء إلكتروني مصري مبني على **WordPress** و **WooCommerce**.  
يحتوي هذا المستودع حصريًا على الكود البرمجي المخصص (Custom Theme & Custom Core Plugin)، مع عزل تام لملفات نواة ووردبريس والإضافات الخارجية وقواعد البيانات.

---

## 1. المتطلبات البرمجية وبيئة التشغيل (Requirements)

تم اختبار وتطوير المشروع للتوافق مع المعايير التالية:

| المكوّن | الإصدار المطلوب / المختبر | ملاحظات |
| :--- | :--- | :--- |
| **PHP** | `8.2+` (مختبر على `8.2.29`) | يتطلب تفعيل إضافات `mysqli`, `curl`, `mbstring` |
| **WordPress Core** | `6.6+` (مختبر على بيئة `7.1.2`) | تثبيت نظيف عبر LocalWP أو بيئة Staging |
| **قاعدة البيانات** | `MySQL 8.0+` أو `MariaDB 10.6+` | ترميز الجداول الافتراضي: `utf8mb4` |
| **WooCommerce** | الإصدار `9.0+` | إضافة خارجية (تُثبت منفصلة ولا تُرفع في المستودع) |
| **اتجاه الواجهة** | RTL افتراضيًا | دعم كامل للغة العربية والخطوط المتجاوبة |

## 2. هيكل المستودع (Repository Structure)

تم تنظيم المستودع ليكون مستقلاً عن مجلد تثبيت ووردبريس العام:

```text
egypt-fashion-store/
├── .gitignore                      # استبعاد النواة، قواعد البيانات، الأسرار، والوسائط
├── README.md                       # دليل التثبيت والتشغيل والمعايير
├── themes/
│   └── egypt-fashion-child/        # القالب الفرعي (Child Theme) للمتجر
│       ├── style.css               # تعريف القالب الفرعي وهوية المتجر وتنسيقات RTL
│       └── functions.php           # دعم ووكومرس، تحميل الخطوط والأصول، وربط القالب الأب
└── plugins/
    └── egypt-fashion-core/         # إضافة الوظائف المخصصة للمتجر (Core Plugin)
        └── egypt-fashion-core.php  # منطق العمل الخاص (العملة المصرية، أرقام الهواتف، التخصيصات)
```

## 3. خطوات التثبيت والتشغيل المحلي (Local Setup)

### الخطوة 1: استنساخ المستودع (Clone)
قم باستنساخ هذا المستودع في مجلد العمل الخاص بك:
```bash
git clone https://github.com/itachi-void/egypt-fashion-store.git
```

### الخطوة 2: ربط الكود بموقع ووردبريس المحلي
انسخ أو أنشئ روابط رمزية (Symlinks) لمجلدات الكود داخل مجلد `wp-content` بموقعك:
* انسخ `themes/egypt-fashion-child` إلى `wp-content/themes/`
* انسخ `plugins/egypt-fashion-core` إلى `wp-content/plugins/`

### الخطوة 3: تثبيت وتفعيل WooCommerce والإضافات الرسمية
لا يتم تضمين كود WooCommerce في هذا المستودع لكونه إضافة مفتوحة المصدر يتم تحديثها رسميًا. لتثبيتها عبر WP-CLI:
```bash
wp plugin install woocommerce --activate
```

### الخطوة 4: تفعيل القالب الفرعي وإضافة المتجر
```bash
wp theme activate egypt-fashion-child
wp plugin activate egypt-fashion-core
```

## 4. تنبيه هام بشأن قاعدة البيانات وبيانات WooCommerce

> [!IMPORTANT]
> **إعدادات ووكومرس، تصنيفات المنتجات، المنتجات، خيارات الشحن، والطلبات محفوظة بالكامل في قاعدة البيانات (MySQL Database) ولا تنتقل تلقائيًا عبر Git.**
> * **Git يتتبع:** ملفات الكود فقط (CSS, PHP, JS, Assets).
> * **قاعدة البيانات تحفظ:** بيانات المنتجات، إعدادات بوابات الدفع، سجلات الطلبات، وأسعار الشحن.
> * لنقل الإعدادات بين بيئة التطوير (Local) وبيئة المراجعة (Staging)، استخدم عمليات تصدير/استيراد قاعدة البيانات عبر WP-CLI أو أدوات ترحيل قواعد البيانات المعتمدة:
>   ```bash
>   # تصدير قاعدة البيانات محليًا
>   wp db export store-backup.sql
>   
>   # استيرادها على البيئة التجريبية (مع تحديث النطاق)
>   wp db import store-backup.sql
>   wp search-replace "http://store.local" "https://staging.store.com"
>   ```

## 5. قواعد الأمان واختبار البريد الإلكتروني (Safety & Mail Testing)

* **حجب البريد الحقيقي محليًا:**  
  عند الاختبار المحلي في ووردبريس، احرص على استخدام أدوات حجب البريد أو محاكاة الإرسال (مثل Mailpit المدمج في LocalWP أو إضافات `mu-plugins` محلية خاصة بالحجب).  
  **تنبيه:** لا ترفع أي ملفات حجب بريد محلية أو سجلات بريد ضمن هذا المستودع؛ يجب أن يظل كود الإنتاج نظيفًا تمامًا.
* **إدارة الأسرار والمفاتيح:**  
  لا تضع أي كلمات مرور، أو مفاتيح API، أو بيانات بوابات الدفع داخل ملفات الكود. استخدم دوال إعدادات ووكومرس الآمنة أو متغيرات البيئة.

## 6. المساهمة وسير العمل (Workflow)

1. التطوير يتم دائمًا على فروع مخصصة (Feature Branches).
2. مراجعة التوافق البصري ودعم RTL وتجاوب الهواتف قبل الدمج.
3. تدقيق صياغة الـ PHP وخلو الكود من التحذيرات عبر `php -l`.
